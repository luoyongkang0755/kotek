## 3. 工作项详解（PPT 每节可直接拆页）

### 3.1 公平对比批与 place 死锁定位（工作项 1）

**背景**：holddown 模型的已有数据多在晚间采集，抓取踢转率随负载波动大，缺公平基线。

**方法**：午后低负载（load 0.16）跑满 10 遍（`e2e10_holddown_final`），逐次提取
CLOSE_GRIPPER 遥测 + 任务日志归因。

**数据**：

- 0/10 COMPLETE；10 个已挂盒**全部焊接、偏斜 0.0°**（墙面侧 100% 可靠）
- 失败 8/10 在抓取相位（踢转 ~90° / 接触未中），**2/10 命中新失败类**：
  `MOVE_ARM_TO_PLACE failed: cartesian path only 0.833333 complete`

**根因定位（跨配置证据链）**：

| 证据 | 配置 | 现象 |
|---|---|---|
| contact_place4 run9 | x=0.398、无盒附着 | 同样 0.833333 |
| holddown3 run4 | x=0.39、有附着 | 同样 0.833333 |
| holddown_final runs 2/3 | x=0.39、有附着 | 同样 0.833333 |

分数恒为 5/6、三次重试一致 → **直线插补进入正 y 侧伸展目标时末段 1/6 确定性无解**
（原始 IK/碰撞边界），与 _WALL_X、与 carried-box 附着均无关；旧代码直接 ABORT 整遍。

### 3.2 OMPL 兜底修复（工作项 2）

**改法**：`piper_manipulator_node.cpp` — 笛卡尔直线失败（3 次重试）后回退 OMPL
关节空间规划（沿用 RETREAT_ARM 既有模式），全败才 abort。墙面结果仍由
held-box 校验 + PRESS + 释放后确认三重把关。

**验证**（`e2e10_holddown_fallback`，10 遍）：**2/10 COMPLETE 4/4**，且两遍均实际命中
死锁并被 OMPL 救回（无兜底则又是 0/10）；其余 8 遍全为抓取相位失败。

### 3.3 抓取混沌专项（工作项 3–6，本阶段最大块）

**问题定义**：PhysX 点接触无扭转摩擦 → 爪闭合时盒子在指缝间被踢转（~90°）、
重试后接触未中、极端时整盒被震下 riser。出现在全部历史配置中，与磁模型无关。

**A 组基线**（20 遍合并、81 次抓取尝试）：成功率 34.6%、踢转失败率 56.8%、
接触未中 8.6%、有接触闭合的偏斜中位 **56.1°**。

**慢闭合 v1 — move_group 速度缩放（证伪，重要负面结果）**：

-  hypothesis：0.15 速度缩放 → 准静态接触，摩擦自居中
-  实测：参数确认加载，但 46 次闭合耗时恒 0.57–0.94s（缩放从未落实到执行轨迹）
-  处置：**中途中止损**，该批数据作废 —— 没有这一步就没有后面的 v2

**慢闭合 v2 — 直发 FJT 手写时序（正结果）**：

-  实现：`moveGripperToWidthTimed()` 把闭合 ramp 直接发给 isaac_joint_bridge 的
   FollowJointTrajectory action，时间戳手写；桥按 time_from_start 1:1 插值、
   stall 判定在轨迹窗之后（慢斜坡安全）。绕开 move_group 时间参数化。
-  配套参数：`grasp_close_duration: 4.0`（0=旧路径）；补 `control_msgs` 依赖。
-  被否方案及理由："预闭合到盒宽+余量"——实测指尖下降时离盒面已仅 2.5mm/侧，
   接触前行程总共 1.2mm/指，预闭合无物理意义。

**A/B2 对比**（10 遍，闭合中位 3.91s）：

| 指标 | A 组 | B2 慢闭合 | 变化 |
|---|---|---|---|
| 抓取成功率 | 34.6% | **53.8%** | +19 pt |
| 踢转失败率 | 56.8% | **34.6%** | −22 pt |
| 接触偏斜中位 | 56.1° | **21.7°** | −34° |
| COMPLETE 4/4 | 0/10 | **4/10** | 0 → 40% |

到达墙面的盒仍 100% 焊接、0.0°。

**残余链与轻挤压实验（工作项 6，负面结果）**：

-  B2 失败归因：残余 kick 把盒**震下 riser**；反应式重抓（TF 实时位姿，窗 9.6cm）
   机制本身工作正常（实测自动对准 0.025m 偏移的盒）
-  hypothesis：挤压 10N→约一半（grasp_width 0.018→0.026）→ 踢转扭矩减半
-  实测（`e2e10_holddown_grip026`，10 遍）：成功率 46%、踢转率 44%、COMPLETE 3/10
   —— **全面差于 0.018**；无 LIFT 滑脱（历史 0.026 弃用原因是 riser-hold bug 误判，已澄清）
-  **机制认知更新**：更紧的挤压反而**更早钳制盒子的偏航自由度**；轻挤压给盒子更长的
   自由旋转窗口直到对角自锁。终态配置 = 4.0s 慢闭合 + 0.018 挤压。

### 3.5 三角度俯视图解（工作项 8，回答老师的几何问题）

产出 `grasp_angles_topview.png`（+可复现脚本）：俯视分离 **物体偏航 ψ_obj**、
**进近偏航 ψ_app = snap(atan2(y,x), π)**、**夹爪/TCP 偏航 ψ_tcp**。

核心结论：**ψ_tcp ≡ ψ_app (mod π) 是构造使然**（TCP +Z = 进近向量、+X = up × approach）；
snap 保证 ψ_tcp ≡ ψ_obj (mod π)，钳口平行盒面跨夹 3.5cm 宽度；不 snap 则钳口对角
跨角（V-grip，实测翻倒）。选 π 而非 π/2：8cm 边超过钳口 4cm 最大开度，只有 3.5cm
边可跨夹。数值与真实运行日志核对一致（link6 指尖偏移 0.135m）。

## 5. 当前终态配置

- 磁模型：接触才启动（面-墙 <6mm），3N 法向保持 + 对齐扭矩，焊接门 偏斜 <23°
- 放置管线：PLACE(面前 2cm) → 确认 → PRESS(+3cm) → dwell 1.5s → 开爪 → 焊接 → 确认 → 撤退
- 抓取管线：4.0s 手写时序慢闭合 + grasp_width 0.018 + 踢转检测(30°) + 反应式重抓
- MOVE_ARM_TO_PLACE 笛卡尔失败 → OMPL 兜底

## 6. 残余问题与下一步候选

1.  **抓取踢转（唯一剩余失败源）**：34.6% 踢转率、重试后接触未中/震落 riser。
    候选：分段 creep 闭合带静止 dwell；PhysX 扭转摩擦参数（若 Isaac 暴露）；
    抓前预对准。
2.  **负载敏感性**：踢转率随机器负载波动（下午 ~15%、晚间 50%+），验证实验需在
    低负载时段进行（录制时已实测负载 460% CPU 下 move_group 超时连锁失败）。
3.  **0.833333 死锁**已被兜底掩盖但未根治（IK 边界本身仍在）。
