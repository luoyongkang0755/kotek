## 1. 环境退化说明（不计入对比）

本批末尾 runs 46–50 遭遇**环境性故障**，与焊门改动无关：
- run 46：move_group 超时 abort（任务未开始搬运）；
- runs 47–50：**Isaac 启动即崩溃**（breakpad crash dump，连续 4 次，
  每次约 3 分钟启动失败）。疑似连续 46 次运行的 GPU 资源累积/未释放。
- 有效样本 = runs 01–45（全部 COMPLETE，单遍耗时 379 s，与基线持平）。

## 3. 结论

1. **Task 1 达标且符合预测**：门限边缘拒焊类 31→0 全部消除（预测"救回全部
   31 例"），单盒焊接率 67→82.2%（预测 ~82%），4/4 全焊率 12→40%。
   23° 门仍挡住全部卡死类（本批卡死 0 例；偏斜带上限 22.1° < 23°）。
2. **剩余失败 100% 为搬运滑落（slip）**，且高度集中于外侧目标
   （s4×19、s1×7、s3×6，s2 零滑落）——正是 Task 2 的目标。
   滑落机制（基线批次逐 tick 取证）：抓取后盒在指间缓慢翻转滑脱贯穿整个
   搬运（持盒全程角速度 4.5–7.7 rad/s），最终掉在墙脚。
3. 焊门改动无时间/稳定性代价；末尾环境崩溃提示**长批量需留意 GPU 累积
   问题**（后续验证批改为 10 遍）。
