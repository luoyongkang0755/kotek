# 壁挂 E2E 50 遍批量验证报告

日期：2026-09-13
方法：`run_e2e_50.sh`（本目录）严格串行执行 50 遍完整端到端——每遍重启 Isaac
（headless `run_wall_stage.py`）+ 重启容器栈 + 45 s warm-up + `wall_mount_task`
（遵守"重跑需双侧刷新"约定）。每遍记录任务结果、焊接数、各 sensor 焊接偏斜、
abort 阶段/错误原文、耗时与失败分类；非全焊运行的完整日志留存于
`fail_logs/`。原始 CSV 见 `results.csv`，逐盒失败明细见 `per_box_failures.csv`。

## 1. 总体结果

| 指标 | 数值 |
|---|---|
| 任务完成率（wall-mount task COMPLETE） | **50/50 = 100%** |
| 零 abort / 零超时 / 零基础设施失败（Isaac/栈启动） | 50/50 |
| move_group 崩溃（"Cannot push…" / SIGSEGV） | **0 次**（修复前连续 2/2 复发） |
| 单盒焊接成功率 | 134/200 = **67.0%** |
| 单遍 4/4 全焊 | 6/50 = 12% |
| 单遍焊接数分布 | 4 焊×6，3 焊×25，2 焊×16，1 焊×3 |
| 每盒焊接率：s1 / s2 / s3 / s4 | 72% / 74% / 60% / 62% |
| 单遍耗时 | 376–385 s（很稳定） |

结论：修复后的任务**流程层完全可靠**——规划、搬运、move_group 稳定性在 50
遍压力测试中零故障；剩余问题全部集中在最后一步"磁吸焊接"的物理成功率上。

## 2. 失败模式分析（66/200 盒未焊，3 类）

### 2.1 门限边缘拒焊 gate_borderline — 31/66（47%）

盒被磁铁正常捕获、贴在墙上（d≈0.015 m，in_range），但平衡偏斜
**15.1–22.1°（中位 15.5°）**，超过 15° 焊接门而未焊，靠磁力贴墙。
焊接成功盒的平衡带为 **13.6–15.0°（中位 14.6°）**。

即：偶极子对齐的自然平衡带（约 13.6–22.1°）正好横跨 15° 门，门把平衡带的
上半部分全部拒之门外。分布按目标位置分化：s2×13、s3×14（内侧目标为主）、
s1×5、s4×1。

### 2.2 掉落墙根 slip_near_wall — 33/66（50%）

盒在放置阶段于墙边丢失，直接掉到**墙脚地面**（末态 x≈0.31–0.37、z≈0.02，
多数呈 90° 平躺，落点 y ≈ 目标 y），离开 attract range 后不再受力。
**强烈集中于外侧目标：s4×18、s1×9；内侧 s2 为 0，s3×6。**

原因：外侧目标（y=±0.15）需要最大的臂展与最长的 preplace 摆动，摆动惯量
把盒从指间撬出（与 wall_mount.yaml 中 carry scaling 注释记录的机制一致：
PhysX 点接触无扭转摩擦）；臂全伸端 KDL 5 ms IK 精度下降也可能使 TCP 实际
到达位姿偏离规划，盒先撞墙再脱手。

### 2.3 卡死歪贴 gate_jammed — 2/66（3%）

盒以 29.5°/43.5° 大偏斜被磁力按在墙上卡死（接触几何卡滞，偶极子扭矩
τ≈1e-4 Nm 无力纠正）。罕见。

## 3. 数据支撑的改进建议（按预期收益排序）

1. **焊接门 15° → 23°**：本样本中平衡带上限 22.1°、卡死下限 29.5°，23°
   门可把 2.1 类（31 例）全部转为成功、同时继续挡住 2.3 类卡死。门原设计
   目的是挡住 45.8° 级歪焊（见 wall_mount_fix_report.md §2.3），23° 仍保留
   该功能。预期单盒焊接率 67% → ~82%。
2. **外侧目标（s1/s4）的防掉落**：对长摆动段进一步降低 carry
   velocity/acceleration scaling，或在释放前增加"盒在爪中"校验（当前盒丢失
   任务仍报 COMPLETE）。预期消除 2.2 类的大部分（33 例）。
3. 长期：优化 release 姿态把自然平衡带整体下压（当前释放偏斜 ~24°，扭矩
   收敛后落在 13.6–22.1°），而非无限放宽门限。

若 1+2 全部落地，按本样本推算单盒焊接率可达 ~95%+、4/4 全焊率从 12% 升至
~80%+。
