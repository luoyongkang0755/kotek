## 0. 终态设计（2026-09-23，用户定案"磁力只做贴合后的保持"）

**磁模型**：接触才启动——盒磁面中心距墙面 <6mm（`MAGNET_ATTRACT_RANGE`
的新语义=接触阈值）才施加力：法向保持力 3N（墙接触法向承重、摩擦抗剪切，
3N×0.9 >> 0.49N 盒重）+ 小对齐扭矩（坐平盒面，上限 0.002 N·m，正比于
sin(偏斜)）+ 重力前馈 + 线性阻尼。**无任何预接触力**——没有径向捕获、没有
横向吸附点、没有距离力场；摆放与对位全部由机械臂完成。焊接门限：面-墙距
<8mm + 静止 + 爪开 + 偏斜 <23°。偶极子公式整体退役（近场点偶极近似失效、
距离触发架构病态，见 §3 考古）。

**管线流程**（piper executePlace）：PLACE 到面前 2cm（holddown2 实测：更深
的位姿让关节残差 0.03rad 超控制器 2s 结算窗 → execute 超时）→ 位置确认
（held-box 校验 = "位置对了"门）→ **PRESS 一按**（+3cm 沿墙法向，低 fraction
非致命）→ 静止 dwell 1.5s → 开爪 → 磁铁承重 → 焊接 → 释放后确认（Phase 1
层）→ OMPL 撤退。

## 1. 目标与设计

按"磁力只做贴合后的保持"的真实物理重构：机械臂把盒**压贴到墙上**（携带
碰撞物体建模让 planner 保证盒角不进墙），手指在墙的支撑下打开，磁铁只负责
抗剪切滑落，爪开后焊接，释放后 TF 确认，再撤退。

## 2. 探针级成果（3/3 PASS，全部实测标定）

1.2cm 射程下的接触物理被完整解决，每个参数都有失败-修复记录：
- **软边界（4mm 滚降）**：硬 d<range 开关在边界泵出极限环（重力前馈开关 +
  轨道进动，盒在 13-14mm 处永动）→ 软边界后轨道消亡
- **降速帽 0.3→0.05 m/s**：1.2cm 射程下 0.3 帽就是进近速度，盒以帽速击穿
  3mm 死区弹回 → 降帽后收敛
- **近接触平台（4mm 内 taper≥0.6）**：真实磁铁贴得越近拉得越狠；taper 归零
  造出 1mm 浮空振荡带（速度 0.03-0.05 永不住手）→ 平台后压贴坐实
- **焊接门 0.04→0.008m**：旧门在 1.2cm 射程内是空门，盒悬停 12mm 被"空中焊"
- **偏置盒坐平 0.0°**：30° 斜置入射被压贴坐平到 0.0°——真实冰箱磁铁行为，
  顺带回答了"为什么贴不平"（旧配置的平衡带 14-15° 是 10cm 隔空捕获的代价）

## 3. E2E 集成：六批排障链与最终阻塞

| 批次 | 发现 | 处置 |
|---|---|---|
| 1 | 近接触平台让磁铁在爪中拖盒向墙法线，45° 姿态门（参考系=approach 方向）10/10 拒绝 | 门放宽 50° 兜底 |
| 2 | 45° 倾斜挂高 14.1mm 垂直偏移 > 整个射程，零入窗 | _WALL_Z 补偿 |
| 3 | 补偿符号反（盒心垂在指尖点下方） | 一正一负两次实测锁死几何量 |
| 4 | "指尖点"是数学虚构：重定向搬运盒钳在 link6 附近（偏移 −30.7/−16.7mm），公式差 9mm | 直接实测常数 _WALL_X=0.4113 |
| 5 | run_03 首次入窗：d=0.0049 但以 0.154m/s/3.2rad/s 高速穿窗丢失 | 加 press_dwell 1.5s |
| 6 | **带 dwell 后盒仍 0.09m/s、2.7rad/s 穿窗**（run_04：d=0.0026、f=1.8N、偏斜 0.1° 的完美条件下仍丢失） | 判定为架构级阻塞 |

**最终阻塞（架构级）**：磁铁在 5-12mm 预接触带内的力/扭矩（1.8N/0.002N·m）
**超过指缝摩擦对 50g 盒的约束**——压贴和 dwell 期间磁铁持续扭转/推移爪中盒，
开爪瞬间盒已带速度和自旋，永远拿不到"静止+爪开+贴墙"的焊接窗口。这不是调参
能解决的：接触放置要求磁铁在"墙能承接载荷"之后才全力作用，而按距离触发的
力律必然在指 still gripping 时介入。

## 4. 复活路径（按优先级）

1. **接触触发的力律**：近场平台改为"盒面实际接触墙之后才启用"（磁图需要一
   个接触输入——PhysX contact sensor 或盒面 x≈0.40 判定），让磁铁只在墙承接
   后全力作用。这是架构级修改，预计 1-2 轮迭代。
2. **快开爪 + 弱近场**：近场 taper 压到 0.2 以下（爪内不打滑），开爪后靠
   0.49N 重量+墙支撑贴住，再由中程力坐实——牺牲部分"啪嗒坐平"效果。
3. 演示用途继续用已验证的 10cm 捕获配置；接触放置作为物理研究分支推进。
