## 3. 结论与遗留

- Task 2 的验收语义达成：**任何盒丢失都不再报 COMPLETE**（三层校验全部
  loud abort）；外侧目标的长摆动减速已按距离门控实现且不拖慢短程。
- 剩余失败是抓取闭合接触混沌（点接触无扭转摩擦），重试 3 次后的残余由
  物理决定。**注意强时变特性**：同代码下午批次焊接率 85%、晚间 42.5-50%，
  验证与演示建议安排在机器低负载时段。后续方向：抓取几何层面（慢闭合/预
  对准，或在 CLOSE 前用 TF 二次对准——盒被丢下后可能仍在滚动，当前 TF 读数
  是 pregrasp 时刻的）、或 Task 3 释放姿态优化。
- 遗留观察：s4 角点（-0.109,+0.109）从基线批次起就是最差目标（踢转 3/3
  集中出现），值得单独做几何检查。
