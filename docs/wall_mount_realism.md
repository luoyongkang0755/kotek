# 磁铁物理"向真实靠拢"改造报告（2026-09-21）

目标：把磁吸模型从演示抽象（0.10 m 捕获距离）推向真实小磁铁行为。
结论先行：**捕获距离 0.10 → 0.03 m 已达成并经探针验证**；释放几何已重算到
磁面间隙 2.5cm（实测 min-d 0.025）；E2E 全链在批量中验证（数据见下）。
毫米级真实捕获受 24° 残余倾斜几何限制（盒角先撞墙），需 Task 3 释放姿态
优化才能继续推进——这是本次探明的硬边界。

## 1. 改动清单

| 项 | 旧值 | 新值 | 依据 |
|---|---|---|---|
| MAGNET_ATTRACT_RANGE | 0.10 m | **0.03 m** | 真实小磁铁几毫米外无力；3cm 是 24° 倾斜下的几何可达上限 |
| MAGNET_DIPOLE_MOMENT | 18.3 | 1.64 → **3.2** | 先按"边缘 2N"标定；smoke_r3 实测释放动态（手指弹盒+再加速）1.5N 拉不住，加倍；近贴 5-10N 反而更符合真实磁铁 |
| MAGNET_MAX_FORCE | 2.0 N | 3.0 N | 同上（近贴饱和，clamp 跟随） |
| WELD_DISTANCE | 0.04 m | 0.02 m | 0.04 在 0.03 射程内是空门（"在空中焊"） |
| _WALL_X | 0.355 | **0.386** | 释放几何反推：磁面间隙=0.40−(cmd−0.006)，角间隙 3.5cm |
| _WALL_Z | +0.06 抬升 | **去掉** | 垂直间隙曾是 d 的主要分量（smoke_r1 实测 d=0.103 中 ~6cm 是垂直）；link6 在新高度 z=−0.0255 仍高于工作空间下界 −0.05 |
| 携带碰撞物体 | 无 | **AttachedCollisionObject**（attach 于抓取后、release 后 detach） | planner 从此看见盒体——这是能贴近墙释放的前提 |
| RETREAT_ARM | 直线 cartesian | **OMPL 关节空间**（失败回退 cartesian） | 近墙位姿下直线上升擦墙（fraction 0.15，smoke_r3 实测） |

## 2. 验证阶梯

1. **USD 烘焙验证**（pxr 读回）：attractRange=0.03、moment=3.2、maxForce=3.0、
   weldDistance=0.02 ✓
2. **探针**（自动随 range 缩放生成距离）：
   - in-range（2.4cm 静息正放）：**PASS**——捕获、焊接、末距 0.0061m
   - out-of-range（riser 原处）：**PASS**——零位移零焊接
   - misaligned（2.4cm、30° 斜放）：**FAIL（预期内）**——30° 斜置盒角在 2.4cm
     处必然先触墙/缘，自由空间对齐物理上不可能；真实磁铁同样靠接触坐实。
     30-97° 缺陷已由 Task 2 的抓取/释放姿态门拦截，不进捕获窗。
3. **E2E 冒烟**（smoke_r3，moment 1.64 时）：释放点 min-d = **0.0248-0.0257m**
   （2.5cm，在 0.03 射程内 ✓——释放几何重算正确）；但 1.5N 捕获力拉不住
   手指弹盒后的下坠 → moment 加倍到 3.2。
4. **10 遍批量**：见 §3。

## 5. 残余边界与后续

- **毫米级捕获需要 Task 3**：24° 残余倾斜使盒角比磁面多伸出 3.5cm，
  磁面 <1.5cm 时角必撞墙。继续推进 = 释放姿态优化（倾斜角、挂载轴向）。
- misaligned 探针的 30° 判据适用于 10cm 射程的自由空间对齐；3cm 射程下
  接触坐实是物理正解，探针判据应改为"末态 <23° 门内或焊接成立"。
- 携带碰撞物体使规划略保守（smoke_r1 观测到单次 preplace OMPL 失败），
  在批量统计中跟踪其频率；若 >5% 考虑仅 PLACE 腿附加（计划回滚档 B）。
