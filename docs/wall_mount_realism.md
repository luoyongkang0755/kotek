## 1. 目标与结论

目标：捕获距离 0.10 m → ~0.03 m（真实小磁铁几毫米外无力）。
结论：**3cm 捕获距离本身达成且经探针验证，但 E2E 全链失败（2.5% vs 同时段
基线 50%），触发计划中的回滚预案**。根因不是捕获距离，而是**释放动态裕量**：
10cm 射程当年同时在兜"手指弹盒 + 倾斜释放"的物理余量，3cm 射程把这个隐藏
依赖暴露了出来。

## 3. 批量失败分析（e2e10_realism，10 遍）

单盒焊接率 **2.5%**（1/40），失败分布：
- 5 遍：抓取踢转 3/3（混沌物理，与旧配置晚间表现相同，非本改造引入）
- 3 遍：释放前姿态门 30.7-31.3° 拦截（贴边拒绝——旧配置下这些盒进 10cm
  射程后会被扭矩扳回再焊；3cm 射程内 31° 斜盒直接触墙缘失去自由对齐空间）
- **run_07：COMPLETE 但 0 焊接**——4 次释放全部 orientation/距离合规、全部
  未被捕获（min-d≤3cm 仍掉落）。**暴露新缺口：释放后无焊接确认层**，
  "盒在释放瞬间合规"≠"盒被捕获"
- run_06：仅 1 焊（5.5°，干净捕获证明 3cm 物理可工作）

## 4. 回滚判定与依据

计划预案："单盒焊接率低于基线 ≥5 个百分点 → 回退 USD 磁图与释放点"。
2.5% vs 50%（同时段同校验体系基线）远超阈值 → **回滚**。保留发现：

1. **3cm 静息捕获是成立的**（探针 + run_06 实测焊接）；
2. **释放几何方法学成立**：碰撞物体建模 + 反推释放点把 min-d 从 10.3cm
   做到 2.5cm，这套方法 Task 3 可直接复用；
3. **硬边界**：24° 残余倾斜 → 盒角比磁面伸出 3.5cm → 捕获距离无法低于
   ~1.5cm；且 3cm 射程对释放动态的容差太小（弹盒、31° 贴边盒）。
